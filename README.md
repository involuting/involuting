### KitPvP *(Private)*

A modern KitPvP core built around scalable backend architecture, modular systems, and high-performance gameplay.

Features include kits and abilities, progression, duels, matchmaking, parties, clans, events, tournaments, shops, auctions, crates, and competitive leaderboards.

### Practice *(Private)*

A competitive Practice core featuring ranked and unranked matchmaking, configurable kits, arena management, player duels, parties, and modular match systems.

### Block Hunt *(Public)*

A modern Prop Hunt and Block Hunt implementation for PaperMC, featuring packet-based rendering, custom disguise mechanics, configurable gameplay, and clean architecture.

### Capture the Flag *(In Development)*

A modern Capture the Flag implementation for Paper and Spigot, featuring team-based gameplay, configurable arenas, match management, scoring, and modular mechanics.
